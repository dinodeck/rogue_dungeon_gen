# rogue_dungeon_gen

A single-file, runnable dungeon generator in the style of the original [Rogue](https://howtomakeanrpg.com/r/l/g/rogue.html) 
It prints one 80×24 level to the console.

This is the reference implementation for the article **["How did Rogue Generate its Random Dungeons?"](https://howtomakeanrpg.com/r/a/rogue-dungeon-generation.html)** on [HowToMakeAnRPG.com](https://howtomakeanrpg.com). 

## Run it

.NET SDK 6 or later.

```
git clone https://github.com/dinodeck/rogue_dungeon_gen.git
cd rogue_dungeon_gen
dotnet run
```

Every run gives a different level.
